# Water Bottle Shop Product Showcase UI in Flutter 🍶

A sleek **teal and charcoal product showcase** for a water bottle shop, built with Flutter. It features the **Onyx Bottle** from *The Stone Collection*, with a smooth entrance animation, a gently floating bottle and a **Shop Now** button.

The matte black bottle, brushed steel cap, faceted base and teal background are all drawn in code with `CustomPaint`, so the app uses no images. Text uses the clean **Nunito Sans** font.

The UI is split into small, reusable components, similar to how you would structure a React Native app.

## ✨ Features

- 🎨 Teal and charcoal theme with a curved teal sweep background
- 🍶 Matte black Onyx Bottle with a brushed steel cap and faceted base, drawn entirely in code
- 🎬 Staggered entrance animation for the background, bottle, header, title and button
- 🌊 Floating bottle animation with a floor shadow that shrinks as the bottle lifts
- 👆 **Shop Now** button with a press animation and "Added to cart" feedback
- 🧭 Custom header with menu icon, Swell logo and profile avatar
- 🧩 Reusable Flutter components with a barrel export, similar to `components/index.ts`

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Water-Bottle-Shop-Product-Showcase-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Water-Bottle-Shop-Product-Showcase-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
